## Completed Tasks
1. **Even or Odd** (`task_01_even_odd.py`) — Determines if a number is positive/negative even, odd, or zero.
2. **Largest of Three** (`task_02_largest_three.py`) — Compares three numbers and handles equal values.
3. **Prime Number Checker** (`task_03_prime_checker.py`) — Checks if a number is prime using a loop.
4. **Palindrome Checker** (`task_04_palindrome.py`) — Checks if a word reads the same backward, ignoring case.
5. **Sum of Digits** (`task_05_sum_digits.py`) — Calculates the sum of a number's digits using a `while` loop.
6. **FizzBuzz** (`task_06_fizzbuzz.py`) — Prints Fizz, Buzz, or FizzBuzz across a user-defined range.
7. **Number Guessing Game** (`task_07_guessing_game.py`) — Interactive guessing game with a 5-attempt limit.
8. **Count Numbers** (`task_08_count_numbers.py`) — Counts even/odd numbers and calculates the total sum from 1 to N in one loop.
9. **ATM PIN System** (`task_09_atm_pin.py`) — Simulates PIN verification with a 3-attempt limit.
10. **Number Analyzer** (`task_10_number_analyzer.py`) — Analyzes 10 inputs for min, max, sum, average, and even/odd counts in one loop.
